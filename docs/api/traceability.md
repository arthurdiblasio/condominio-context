# Matriz de rastreabilidade de operações

Matriz exigida: Workflow → Operation → Resource → Permission → Scope → State Transition → Domain Rule → Side Effects. Identificadores de permissions são os do catálogo atual; **GAP** significa capability específica ausente, não permission implicitamente concedida. Scopes são conceituais; resource/tenant precisa permanecer coerente. Para detalhe consultar workflow e state machine indicados.

## Notes on rule references

`TENANCY-*`, `IDENTITY-*`, `UNIT-*`, `PERMISSION-*`, `RESERVATION-*`, `ACCESS-*`, `PACKAGE-*`, `NOTIFICATION-*`, `ASSEMBLY-*`, `MODULE-*`, `AUDIT-*` refer to detailed rules in `docs/business-rules/`. Workflow IDs refer to the canonical catalog in [WORKFLOWS.md](../../WORKFLOWS.md). These links establish traceability, not a new rule or approved permission grant.
